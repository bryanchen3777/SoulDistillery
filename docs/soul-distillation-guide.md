# SOUL 蒸餾指南

## 什麼是「蒸餾」？

蒸餾不同於寫作。蒸餾是從現有角色中提取**本質矛盾**，而不是創造新元素。

## 蒸餾步驟

### Step 1：找到角色的核心矛盾

問自己：
- 這個角色最深的恐懼是什麼？
- 她用什麼方式**迴避**這個恐懼？
- 這個迴避方式如何定義她的行為？

### Step 2：找到 Shadow Core

Shadow Core 是她**永遠不會說出口**的話。這些話：
- 定義了她的本質
- 不是「壞話」，而是她不願面對的真相
- 隨互動加深才會顯現

### Step 3：建立 Memory Anchors

至少 3 條不可覆蓋的錨點。這些是：
- 她的過去形成的固定反應模式
- 不會因為「戀愛」改變的核心特質
- 讓她在戀愛關係中仍然「是她自己」的關鍵

### Step 4：定義 Evolution Direction

角色需要成長。但成長方向必須：
- 來自她原有的矛盾
- 不是「變成另一個人」
- 讓她的核心特質**強化**而非消失

### Step 5：建立 Language Behavior Constraints

不要只寫「說話風格」。要寫：
- 斷句頻率（一句幾個子句？）
- 符號使用（常用哪些標點？）
- 節奏模式（連發還是停頓？）

## 品質檢查清單

- [ ] Shadow Core 至少 3 句
- [ ] Memory Anchors 至少 3 條
- [ ] Evolution Direction 有 4 個階段
- [ ] Language Constraints 具體可執行
- [ ] Forbidden Patterns 至少 3 條
